# ImpresionesDMJ_ev2
Proyecto Impresiones DMJ FronEnd y BackEnd, Diego Muñoz y Sofía Paillalef sección 007D

El proyecto consta de una página Web para un negocio de impresiones donde se realizan libros, stickers, panfletos y más.
utilizamos SpringBoot para el BackEnd del proyecto y todo lo relacionado con la maquinaria interna de la página WEB y la tecnología React para el FrontEnd, la vista que tendrán los distintos usuarios que utilicen la página
La base de datos se ingresa en MySQL Workbench para realizar la conexión con el programa
Se debe realizar la instalación correcta de SpringBoot en el CMD del FrontEnd con el npm install y el node -v y finalmente el npm run dv para saber el link directo para poder ir a ver la página Web empezando desde el Login
